# Pocket Ring (NeoForge 1.21.1)

Anel infinito: clique com o botão direito no chão para criar um círculo de fogo
e ser teleportado para uma dimensão de bolso (mundo plano de deepslate).
Use o anel de novo (no chão ou no ar) para voltar ao ponto de origem.

Rodar: `./gradlew runClient` — build: `./gradlew build`
